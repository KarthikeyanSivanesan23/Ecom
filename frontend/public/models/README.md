# 3D Models for Hero Section

Place your GLB/GLTF model files in this directory:

- `boy.glb` - Male character model
- `girl.glb` - Female character model

## Recommended Model Specs

- **Format**: GLB (preferred) or GLTF
- **Poly count**: 50k-150k triangles per model
- **Textures**: Embedded in GLB, 1K-2K resolution
- **Scale**: Models should be roughly human height (~1.7 units)
- **Orientation**: Facing forward (negative Z direction)

## Where to Find Models

- [Sketchfab](https://sketchfab.com) (free & paid)
- [ReadyPlayerMe](https://readyplayer.me) (avatar models)
- [Mixamo](https://www.mixamo.com) (animated characters)
- [CGTrader](https://www.cgtrader.com) (premium models)

## Fallback Behavior

If models are not placed, the hero will display elegant fallback capsules with the same lighting and animation setup. The 3D scene will still look premium without models.
